# CardVault · Full

这是完整功能版源码，基于用户提供的 `card-main` 源码修改。

## 1.3.0 · 角色卡内部内容查重

- 在「角色卡库」顶部新增 **内容查重** 按钮。比较云端不同角色卡 ID 的角色描述、性格、场景、开场白、备选开场、示例对话、世界书、正则和系统提示等，发现**内容完全相同**、**疑似更新版本**及**高度相似**的角色卡。
- 不只比较卡名或封面；不同名称但内容相近也可能识别。版本号（例如 6.3 / 6.4 / v2）会在匹配角色名时规范化。
- 支持严格 / 均衡 / 宽松阈值；显示相似度、同组卡片及各内容模块的相似程度。可在结果中按需「对比内容差异」（并排显示两卡不同的文字字段），或直接打开角色卡详情人工确认。
- 第一次需要从云端逐张读取卡片内容（最多 4 个并发）；之后仅保存**本机文本指纹缓存**，未变更的角色卡无需再次读取。可点击「重新读取」跳过缓存。可停止扫描，已完成部分会保留指纹缓存。
- 纯本地算法，不使用 AI 分类接口、不消耗模型额度，也不会自动删除或覆盖任何角色卡。相似度只是估算，上传日期不代表真实创作版本先后。
- 仅对当前 CardVault 云端角色卡库查重，不扫描 SillyTavern 本地未上传角色。

- **游玩备份**：保留角色 PNG、完整角色 JSON、聊天 JSONL、绑定世界书等归档 / 恢复功能。

## AI 分类持久化

从 1.2.3 开始，CardVault 云端是 Full 与 Import-Only 两个版本共享分类的主存储。Full 会把当前账号的全部分类打包成一张内部 JSON 角色卡：

`__CardVault_AI_Classification_DB__card2`

并通过现有 `/api/cards/import` 保存到 CardVault，无需修改 CardVault 后端源码。插件自己的卡库列表会自动隐藏这张内部数据卡。

同时保留 SillyTavern `extension_settings` 与 `localStorage` 作为本机镜像 / 迁移来源。Import-Only 只读取云端分类数据库，不负责写入。

> 不要在 CardVault 网站后台手动删除名称以 `__CardVault_AI_Classification_DB__` 开头的内部数据卡；删除它会失去云端分类主副本。

## 快捷入口

点击 SillyTavern 聊天输入栏左下角「魔法棒」→「CardVault · 角色卡库」→ 屏幕中央弹出四项操作，选择其一。旧版常驻悬浮球不再创建。

## 安装

将本目录作为 SillyTavern 第三方扩展仓库根目录，至少保留：

```text
manifest.json
index.js
style.css
settings.html
```

然后通过 SillyTavern 的“扩展 → 安装扩展”使用 Git 仓库 URL 安装。
